# Chess Puzzle Difficulty Classification — Website Source

This is the source code for the project website that displays the results of the
**IS-212 Data Mining** project by Hein Htet Zaw (YKPT-22466), based on the three
original files (project.ipynb, lichess_db_puzzle_sample.csv,
ProjectBook_HeinHtetZaw_YKPT22466.docx).

## What's inside

- `src/` — Next.js 16 (App Router) source:
  - `src/app/page.tsx` — single-page site
  - `src/lib/project-data.ts` — REAL project metrics (extracted by running the notebook)
  - `src/lib/decision-tree.ts` — type definitions + in-browser decision-tree walker
  - `src/components/data-explorer.tsx` — searchable / filterable / sortable puzzle table
  - `src/components/puzzle-predictor.tsx` — interactive feature sliders that walk the
    trained Decision Tree in the browser to predict a difficulty class
  - `src/components/try-puzzle.tsx` — "guess the difficulty" game
  - `src/components/ui/*` — shadcn/ui component set
- `public/data/results.json` — REAL analysis output (stats + sample puzzles +
  exported Decision Tree) generated by `scripts/run_analysis.py`
- `public/downloads/` — the four downloadable project files
- `scripts/run_analysis.py` — the Python script that re-runs the notebook on the
  real CSV and regenerates `public/data/results.json`
- Config: `package.json`, `tsconfig.json`, `next.config.ts`, etc.

## How to run it locally

```bash
npm install         # or: bun install
npm run dev         # or: bun run dev
# Open http://localhost:3000
```

## How to regenerate the analysis JSON

If you want to re-run the notebook analysis on the CSV (for example after
updating the CSV or sklearn):

```bash
pip install pandas numpy scikit-learn python-chess mlxtend
python scripts/run_analysis.py
```

This trains a Random Forest (200 trees, ~3 min) and a Decision Tree, runs
Apriori, and writes everything to `public/data/results.json`. The website
will pick up the new numbers automatically.

## How to build for production

```bash
npm run build
npm start           # Default port: 3000
```

## How to deploy / self-host

### Option A — Vercel (easiest)
1. Push this folder to a new GitHub repository.
2. Go to https://vercel.com, "Add New -> Project", import the repository.
3. Vercel auto-detects Next.js. Accept defaults and click "Deploy".

### Option B — Netlify
1. Push to GitHub.
2. Go to https://app.netlify.com -> "Add new site -> Import an existing project".
3. Build command: `npm run build`. Publish directory: `.next`.

### Option C — Any Node host (Render, Railway, Fly.io, a VPS)
1. Push the repository to GitHub/GitLab.
2. Connect the host to the repo, set build command `npm run build` and start
   command `npm start`. Expose port 3000.

### Option D — Static export (GitHub Pages, S3, Cloudflare Pages, Nginx)
1. In `next.config.ts`, add `output: "export"` to the config object.
2. Run `npm run build`. This produces an `out/` folder with a fully static site.
3. Copy the contents of `out/` to your static host's web root.

> Note: with `output: "export"`, the files in `public/downloads/` and
> `public/data/results.json` are automatically copied into the static `out/`
> folder — visitors can still download the project files and the interactive
> sections work without a server.

## Project background

- **Course**: IS-212 Data and Knowledge Mining
- **Institution**: University of Computer Studies, Yangon (2025-2026)
- **Dataset**: 50,000-puzzle sample from the Lichess Open Database
- **Goal**: Predict puzzle difficulty (Easy / Medium / Hard / Expert) from
  board features and metadata without using the rating value itself, plus
  descriptive Apriori mining.
- **Best model**: Random Forest — 62.08% accuracy, 0.5824 macro F1 on the
  10,000-row held-out test set (4.3x over the majority-class baseline).
